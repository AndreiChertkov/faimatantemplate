# faimatantemplate


## Описание

Проект faimatantemplate (Faculty of Artificial Intelligence; MAThematical ANalysis; TEMPLATE) представляет собой **шаблон LaTeX-проекта** для создания учебных материалов по математике (и смежным дисциплинам), подготовленный в рамках работы над учебником по математическому анализу для факультета искусственного интеллекта МГУ.

> Шаблон распространяется свободно при условии указания автора дизайна в итоговом документе. Возможный пример указания авторства приведён в файле `content/cover_verso.tex`.

> Текущая версия шаблона: **1.0.0**. Результат сборки демонстрационного PDF-файла доступен по [ссылке](https://disk.yandex.ru/i/P2Mf10XfIznsrg).


## Основные возможности

### Руководство по стилю оформления

В папке `content/appendix/styleguide/` находится подробное руководство по стилю оформления. Оно фиксирует правила математического набора, использования формул, списков, ссылок, тире, кавычек, пробелов, семантических блоков и собственных команд. Руководство может использоваться авторами и редакторами как справочник, а большими языковыми моделями — как формальное описание требований к обработке исходного LaTeX-кода.

### Семантические математические блоки

Готовые команды-обёртки для типовых математических элементов с единой сквозной нумерацией и собственным цветовым кодом:
- `\defi` — определения (**О**),
- `\stat` — утверждения (**У**),
- `\lemm` — леммы (**Л**),
- `\theo` — теоремы (**Т**),
- `\conc` — следствия (**С**),
- `\exam` — примеры (**П**),
- `\note` — замечания (**З**),
- `\algo` — алгоритмы (**А**),
- `\code` — программный код (**К**),
- `\task` — задачи.

Определения, утверждения, леммы, теоремы, следствия, примеры, замечания и алгоритмы имеют собственное цветовое оформление и используют общий счётчик, сбрасываемый в начале каждого раздела.

Команды `\defi`, `\stat`, `\lemm`, `\theo`, `\conc`, `\exam`, `\note` и `\algo` поддерживают звёздную форму, создающую ненумерованный блок.

Определения могут содержать список примеров и дополнительное замечание (примечание). Утверждения, леммы, теоремы и следствия могут содержать доказательство и замечание. Примеры могут содержать решение и замечание. Алгоритмы могут содержать описание вычислительной сложности и замечание.

### Дополнительный материал

Первый необязательный аргумент семантического блока управляет отметками дополнительного (необязательного для изучения) материала, который отмечается стилизованной звёздочкой на внешнем поле страницы сгенерированного документа. Параметр `optional` отмечает дополнительным весь блок. Параметр `optional=proof` отмечает необязательным доказательство утверждения, леммы, теоремы или следствия. Параметр `optional=note` отмечает необязательным присоединённое к блоку замечание. Несколько частей можно перечислить одновременно, например, в следующем случае необязательными окажутся доказательство и замечание:

```latex
\theo[optional={proof,note}]{Метка}{Название}{Формулировка}[Доказательство][Замечание]
```

### Именованные гиперссылки

Команда

```latex
\blink{Название объекта в нужном падеже}{Метка}
```

создаёт единую гиперссылку, включающую название объекта и его номер в компактном бейдже. Команда используется для ссылок на нумерованные семантические блоки, рисунки и таблицы. Для ссылок на формулы применяется стандартная команда `\eqref`.

### Единая система обозначений

Файл `style/helpers.tex` содержит команды для единообразной записи:

- арифметических операций;
- логических связок и кванторов;
- множеств и отображений;
- числовых промежутков;
- окрестностей;
- последовательностей и пределов;
- производных и дифференциалов;
- числовых характеристик;
- элементарных функций;
- часто используемых текстовых сокращений;
- и т.д.

Использование собственных команд позволяет централизованно изменять обозначения и уменьшает число типографских расхождений между главами.

### Авторское оформление заголовков
  
Заголовки глав, разделов и подразделов оформляются с помощью TikZ. Нумерованные главы и разделы снабжаются декоративными номерными бейджами. Ненумерованные заголовки выделяются вертикальными метками. Оформление вынесено в отдельные файлы `style/base_chapter.tex`, `style/base_section.tex` и `style/base_subsection.tex`.

### Программный код и вывод программы
  
Команда `\code` подключает исходный файл на языке Python и при необходимости добавляет содержимое отдельного файла с выводом программы. Пример:

```latex
\code{code:example}{Пример программы}{code/example.py}[code/example.txt]
```

Для сопоставления вызова `print` со строкой вывода в программном коде можно использовать маркер `\cmo` в строчном комментарии:

```python
print(result)  # «\cmo{1}»
```
В этом случае будет отображён номерной бейдж справа от строки кода.

### Псевдокод

Для записи псевдокода подключён пакет `algpseudocode`. Основные ключевые слова русифицированы. Команда `\algo` позволяет поместить псевдокод в семантический блок и дополнительно указать вычислительную сложность алгоритма и замечание.

### Задачи, решения и ответы

Команда `\task` принимает текст задачи, необязательное решение и необязательный ответ:

```latex
\task{Метка}{Условие}[Решение][Ответ]
```

Решения и ответы отображаются при включённом переключателе `\showtaskdetailstrue` и скрываются при использовании: `\showtaskdetailsfalse`. Это позволяет хранить решения непосредственно в исходном тексте и собирать из одного проекта версии документа для студентов и преподавателей.

### Типографика книги

В шаблоне централизованно настроены:

- геометрия страницы;
- основной, рубленый, моноширинный и математический шрифты;
- колонтитулы;
- оглавление и PDF-закладки;
- подписи к рисункам и таблицам;
- списки;
- микротипографика;
- гиперссылки;
- нумерация формул;
- рабочие пометки `\td` (todo; "сделать") и `\fx` (fix; "исправить").


## Структура проекта

```
.
├── book.tex                  # Главный latex-файл
├── code/                     # Файлы с программным кодом для вставки
│   └── l-01/ ...             # Код для каждой из лекций (глав)
├── content/
│   ├── cover.tex             # Обложка
│   ├── cover_verso.tex       # Оборот обложки (выходные данные)
│   ├── intro.tex             # Введение
│   ├── conclusion.tex        # Послесловие
│   ├── l-01/ ...             # Материал по лекциям (главам)
│   └── appendix/styleguide/  # Руководство по стилю оформления
├── images/                   # Рисунки и логотипы
│   ├── l-00/ ...             # Рисунки для обложки, логотипы и т.п.
│   └── l-01/ ...             # Рисунки для каждой из лекций (глав)
├── style/
│   ├── color.tex             # Цветовые схемы
│   ├── base.tex              # Пакеты и базовые настройки документа
│   ├── helpers.tex           # Авторские команды и сокращения
│   ├── block.tex             # Окружения для лемм, теорем и т.п.
│   ├── base_chapter.tex      # Оформление заголовков глав
│   ├── base_section.tex      # Оформление заголовков разделов
│   ├── base_subsection.tex   # Оформление заголовков подразделов
│   └── code_filter.lua       # Lua-препроцессор для блоков \code
```


## Требования

- Движок **LuaLaTeX** (используется `fontspec`, `unicode-math`, прямые вызовы Lua).
- **Шрифты:** STIX Two Text, STIX Two Math, Libertinus Sans, CMU Typewriter Text, DejaVu Sans Mono.
- **Pygments** (Python-пакет) для работы пакета `minted` (требуется флаг `-shell-escape`).
- Полный дистрибутив TeX (рекомендуется TeX Live актуальной версии).


## Сборка LaTeX-документа

В репозитории содержится python скрипт `build.py`, при запуске которого будет произведена автоматическая сборка документа, а также будет собрана карта документа `map.md`, содержащая краткие описания (метка, название, факт опциональности) всех использованных блоков в каждой главе документа.

Альтернативно можно использовать следующую команду (стоит выполнить дважды для корректной сборки):
```bash
lualatex -synctex=1 -interaction=nonstopmode -file-line-error -halt-on-error -shell-escape book.tex
```
