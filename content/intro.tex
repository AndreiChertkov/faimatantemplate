Данный текст представляет результат генерации при использовании \LaTeX-шаблона \texttt{faimatantemplate}.\footnote{
    См. публичный репозиторий \url{https://github.com/AndreiChertkov/faimatantemplate}.
}
Шаблон может использоваться при создании конспектов лекций, методических пособий, учебников, курсовых и дипломных работ, диссертаций и других документов, содержащих большое количество формул, определений, доказательств, рисунков, таблиц и программного кода.
Настоящий документ одновременно служит кратким руководством по использованию шаблона и наглядной демонстрацией его основных возможностей.

Шаблон построен так, чтобы внешний вид математического документа определялся централизованно, а его содержательная структура оставалась семантической.
Автор указывает, что некоторый фрагмент является определением, теоремой, примером или алгоритмом, а оформление, нумерация, цвет, отступы и дополнительные элементы автоматически задаются стилевыми файлами.
Такой подход упрощает изменение дизайна, поддерживает единообразие большого документа и позволяет сосредоточиться на его содержании.

Для удобства восприятия и запоминания материала принято единое цветовое оформление: каждый значимый элемент изложения помещается в собственный цветной блок, тип которого кратко обозначен в заголовке одной заглавной буквой:
\begin{itemize}
    \item \textbf{\textcolor{deficolor}{Определения}}
        (\textbf{\textcolor{deficolor}{О}})~---
        блоки, в заголовке которых указывается определяемое понятие, а в теле приводится его определение; при необходимости они также содержат наглядные примеры использования и дополнительные примечания.
    \item \textbf{\textcolor{statcolor}{Утверждения}}
        (\textbf{\textcolor{statcolor}{У}})~---
        базовые факты с доказательством, каждому из которых мы даём краткое название для лучшего запоминания.
    \item \textbf{\textcolor{theocolor}{Теоремы}}
        (\textbf{\textcolor{theocolor}{Т}})~---
        центральные и фундаментальные утверждения.
    \item \textbf{\textcolor{lemmcolor}{Леммы}}
        (\textbf{\textcolor{lemmcolor}{Л}})~---
        вспомогательные утверждения, необходимые для доказательства теорем.
    \item \textbf{\textcolor{conccolor}{Следствия}}
        (\textbf{\textcolor{conccolor}{С}})~---
        прямые логические выводы из доказанных утверждений и теорем.
    \item \textbf{\textcolor{examcolor}{Примеры}}
        (\textbf{\textcolor{examcolor}{П}})~---
        подробные разборы применения теории к конкретным задачам.
    \item \textbf{\textcolor{notecolor}{Замечания}}
        (\textbf{\textcolor{notecolor}{З}})~---
        важные комментарии, тонкости, исторические справки и~т.п.
    \item \textbf{\textcolor{algocolor}{Алгоритмы}}
        (\textbf{\textcolor{algocolor}{А}})~---
        пошаговое описание вычислительной процедуры в виде псевдокода.
    \item \textbf{\textcolor{codecolor}{Код}}
        (\textbf{\textcolor{codecolor}{К}})~---
        реализация обсуждаемой математической конструкции или алгоритма на языке программирования Python.
\end{itemize}
В заголовке каждого такого блока, помимо однобуквенного обозначения его типа, приводится составной номер вида $N.M.K$, где $N$~--- номер главы, $M$~--- номер раздела внутри главы, $K$~--- порядковый номер блока внутри раздела.
Отметим, что счётчик является единым для всех типов блоков, соответственно определения, теоремы, леммы и прочие блоки используют общую нумерацию.
Так, заголовок <<\textbf{\textcolor{deficolor}{О}}~1.2.3>> означает, что перед нами блок-определение, имеющий номер 1.2.3, то есть третий по счёту нумерованный блок во втором разделе первой главы.
Для формул, рисунков и таблиц выбрана независимая двухуровневая нумерация на уровне главы.
Например, запись~(1.5) справа от формулы указывает на пятую по счёту формулу первой главы.

Команды \verb|\defi|, \verb|\stat|, \verb|\lemm|, \verb|\theo|, \verb|\conc|, \verb|\exam|, \verb|\note| и \verb|\algo| имеют звёздную форму, создающую ненумерованный блок.
Такие блоки удобны для локальных пояснений, небольших иллюстраций и фрагментов, на которые не предполагается ссылаться из других частей документа.
Команды \verb|\code| и \verb|\task| звёздной формы не имеют.

Шаблон позволяет явно отмечать дополнительный материал, не входящий в обязательную часть изложения.
Параметр \verb|optional| отмечает звёздочкой на внешнем поле весь блок.
Для утверждений, лемм, теорем и следствий можно отдельно отметить необязательность доказательства с помощью параметра \verb|optional=proof|.
Параметр \verb|optional=note| используется для дополнительной заметки, присоединённой к обязательному блоку.
Если необязательными являются сразу несколько частей, они перечисляются в записи вида \verb|optional={proof,note}|.
Дополнительные элементы отмечаются стилизованными звёздочками на внешнем поле страницы.

Для именованных ссылок на нумерованные блоки, рисунки и таблицы используется команда \verb|\blink|.
Она объединяет название объекта, его номер и гиперссылку.
Для ссылок на формулы используется команда \verb|\eqref|.

Для программного кода используется пакет \texttt{minted}, обеспечивающий подсветку синтаксиса и аккуратное оформление длинных строк.
Команда \verb|\code| подключает исходный файл на языке Python и при необходимости добавляет к нему содержимое отдельного файла с выводом программы.
Специальная команда \verb|\cmo| позволяет визуально связать вызов функции \mintinline{python}{print} с соответствующей строкой вывода.
Перед передачей исходного файла пакету \texttt{minted} небольшой Lua-препроцессор удаляет технические маркеры из комментариев, сохраняя выравнивание исходного текста.

Для записи псевдокода используется пакет \texttt{algpseudocode}.
Основные ключевые слова алгоритмов русифицированы.
Команда \verb|\algo| позволяет дополнительно указать вычислительную сложность процедуры и присоединить к ней замечание.

Команда \verb|\task| предназначена для оформления задач.
Решение и ответ могут храниться непосредственно в исходном тексте.
Глобальные переключатели \verb|\showtaskdetailstrue| и \verb|\showtaskdetailsfalse| позволяют собирать из одного проекта версии документа для преподавателей и студентов.

В шаблоне настроены авторские стили заголовков глав, разделов и подразделов.
Нумерованные заголовки глав и разделов снабжаются декоративными бейджами, а ненумерованные заголовки выделяются системой вертикальных линий.
Геометрия страницы, колонтитулы, шрифты, подписи к рисункам и таблицам, параметры списков, микротипографика и гиперссылки задаются централизованно.

Файл \verb|style/helpers.tex| содержит систему команд для единообразной записи арифметических операций, логических связок, кванторов, множеств, отображений, окрестностей, пределов, производных, интегралов, числовых характеристик и элементарных функций.
Использование собственных команд позволяет при необходимости изменить обозначение сразу во всём документе и снижает вероятность типографских расхождений между главами.

Стилевое оформление распределено между несколькими файлами.
Палитра документа находится в файле \verb|style/color.tex|, базовые настройки~--- в файле \verb|style/base.tex|, математические команды~--- в файле \verb|style/helpers.tex|, а определения семантических блоков~--- в файле \verb|style/block.tex|.
Оформление заголовков глав, разделов и подразделов вынесено в отдельные файлы \verb|style/base_chapter.tex|, \verb|style/base_section.tex| и \verb|style/base_subsection.tex|.
Lua-препроцессор для блоков программного кода находится в файле \verb|style/code_filter.lua|.

Документ собирается движком LuaLaTeX.
Для корректной сборки необходимы используемые шаблоном шрифты, пакет Pygments и разрешение на запуск внешних программ с помощью параметра \verb|-shell-escape|.
Для получения правильного оглавления, номеров и ссылок документ следует собрать не менее двух раз.

Подробные правила оформления приведены в приложении~А.
Руководство описывает не только собственные команды шаблона, но и принятые соглашения о формулах, списках, тире, кавычках, пробелах, ссылках и структуре исходных файлов.
Оно может использоваться как памятка для авторов и редакторов, а также как промпт для больших языковых моделей, выполняющих проверку или преобразование исходного \LaTeX-кода.

Первая глава демонстрирует оформление связного математического текста, определений, формул, ссылок, рисунков, таблиц и программного кода.
Во второй главе представлены все основные типы семантических блоков, дополнительный материал, псевдокод, программный код и управление отображением решений задач.
